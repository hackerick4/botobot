# Security

Please do not report security problems in a public issue.

Use GitHub's private vulnerability reporting instead: open the **Security**
tab of this repository and choose **Report a vulnerability**.

The only official downloads are published at botobot.app and are signed.
Release signing public key id: 117a95e2967bf881 (built into
`internal/cli/update_keys.go`). Check a copy with `bot-bridge-cli verify-self`.
